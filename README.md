# MyFridge

Локальное React-приложение для учёта продуктов, сроков годности, напоминаний
и подбора рецептов из собственной базы. ИИ и платные API не используются.

## Запуск

Зависимости установлены, база рецептов подключена. В этой папке:

```sh
npm run dev
```

Откройте [MyFridge](http://127.0.0.1:5173/).
Пустой холодильник можно заполнить самостоятельно или нажать «Посмотреть на
примере». Демонстрационные даты вымышлены; примеры удаляются отдельной кнопкой.

Для установки на другом компьютере понадобятся Node.js 24+ и Python 3.9+:

```sh
npm ci --registry=https://registry.npmjs.org
npm run setup:recipes
```

Поместите ранее собранную `recipes.sqlite` в `data/recipes.sqlite` либо укажите
путь через `RECIPES_DB` в `.env` (образец — `.env.example`). База занимает около
4,3 ГБ и не попадает в Git. Приложение читает её без изменения исходных рецептов.

Собранная версия:

```sh
npm run build
npm start
```

В этом режиме интерфейс и API доступны по `http://127.0.0.1:3001/`.

## Что реализовано

- Отдельная запись для каждой упаковки: продукт, количество, единица, дата
  на этикетке, место и условия хранения, температура по этикетке, примечания.
- Состояния «запечатана», «вскрыта», «закрыта после вскрытия», «без упаковки».
- Запоминание первого вскрытия и автоматический пересчёт срока.
- Карточка продукта с объяснением расчёта и историей изменений.
- Отдельный список просроченных и вручную отмеченных испорченными продуктов.
- Предупреждения о неизвестном сроке после вскрытия и нарушенных условиях.
- Напоминания в приложении, отметки прочитанного, защита от дублей.
- Web Push через service worker и серверную проверку раз в минуту.
- Поиск рецептов по доступным продуктам с выбором приоритета «Использовать
  скорее» или «Больше совпадений».
- Поиск, фильтры по месту хранения, русские подсказки названий.
- Сохранение запасов, настроек, истории и напоминаний между перезапусками.

## Расчёт сроков

```text
срок = min(
  конец указанной на этикетке даты в выбранном часовом поясе,
  первое вскрытие + срок после вскрытия с этикетки
)
```

Вторая граница применяется, когда вскрытие записано и длительность известна.
Повторное закрытие и открытие не сбрасывает первую дату. Если упаковка уже
вскрыта, но длительность не указана, продукт получает статус «Уточните условия»
и исключается из рецептов. Более длительный срок после вскрытия не может
продлить общий срок на этикетке.

Для правил после вскрытия можно отдельно указать место хранения. Температуры
мест хранения задаются в настройках; они не считываются с физических датчиков.
Отклонение температуры или места фиксируется. После исправления условий
необходимо явно подтвердить их проверку в карточке. Это не является оценкой
фактической безопасности продукта. Перенос в морозилку не продлевает срок
автоматически.

Истечение введённого срока и фактическая порча различаются: первое вычисляется
по времени, второе отмечается пользователем. Приложение не определяет порчу по
внешнему виду и не использует универсальные вымышленные сроки хранения.
Основание подхода — [инструкции производителя и маркировка сроков](https://www.foodauthority.nsw.gov.au/consumer/food-safety-home/keeping-food-safe).

## Приоритет рецептов

Из запроса исключаются использованные, просроченные, испорченные упаковки и
продукты с неуточнённым сроком или условиями. По умолчанию выводятся рецепты
без недостающих продуктов; можно разрешить докупить до двух ингредиентов.

Для нескольких подходящих упаковок одного продукта выбирается ближайший
допустимый срок (FEFO). Приоритет «Использовать скорее» сортирует **весь корпус**
по ближайшей дате среди совпавших обязательных ингредиентов. Необязательный
гарнир не может сам поднять рецепт в выдаче. Дата и упаковка, которую стоит
использовать первой, показаны в карточке рецепта.

Количество в запасах не сопоставляется автоматически с количествами в рецепте,
так как исходные единицы и записи неоднородны. Запасы после просмотра рецепта
не списываются. Уменьшить остаток можно в карточке продукта, полностью убрать
упаковку — действием «Убрать из запасов».

Набор содержит 2 323 286 исходных записей, включая 92 144 русских. В английской
части названия и инструкции сохранены на английском; поиск использует конечный
переводной словарь. Источники могут содержать неточности и неполные списки:
сверяйте полный рецепт по сохранённой ссылке.

## Напоминания и Web Push

Порог по умолчанию — 48 часов, изменяется в настройках. Сервер проверяет
продукты при изменениях, чтении состояния и каждую минуту. Напоминания хранятся
в SQLite и не создаются заново после прочтения или перезапуска.

Кнопка «Включить уведомления» запрашивает разрешение браузера и создаёт
подписку Web Push. Вручную включать системные разрешения при установке не нужно.
Закрытая вкладка не препятствует доставке, если сервер работает и браузер/
устройство поддерживает фоновый push. Полностью выключенный компьютер,
остановленный сервер, запрет уведомлений ОС или особенности браузера могут
препятствовать доставке. Встроенный список остаётся доступным независимо от
разрешения на push.

За пределами localhost для service worker нужен HTTPS. Перед публикацией
укажите действительный URL приложения в `VAPID_SUBJECT` и его origin в
`APP_ORIGIN`. Ключи VAPID генерируются один раз и остаются в локальной базе;
приватный ключ не передаётся клиенту. Платная служба рассылки не нужна.

Реальная доставка push на устройство не проверялась во время разработки:
разрешения браузера оставлены пользователю. Проверены генерация напоминаний,
их сохранение, устранение дублей, API и формирование подписки/обработчика.

## Проверки

```sh
npm test
npm run test:recipes
npm run build
```

13 проверок Node.js покрывают сроки и часовые пояса, упаковки, условия,
напоминания и API. Ещё 2 проверки Python проверяют глобальную сортировку
по сроку, выбор ранней упаковки и исключение необязательных ингредиентов
из приоритета. В браузере проверены добавление продукта, сохранение,
карточка, повторное закрытие и подбор по полной базе.

## Файлы и данные

| Путь | Назначение |
|---|---|
| `src/` | Интерфейс React, адаптивные стили |
| `shared/model.ts` | Правила сроков, валидация, общие типы |
| `server/` | Express API, SQLite, планировщик Web Push |
| `recipes/bridge.py` | Поиск по корпусу и FEFO в SQL |
| `recipes/normalizer.py`, `glossary.tsv` | Русские словоформы и словарь ингредиентов |
| `public/sw.js` | Фоновый обработчик push |
| `data/fridge.sqlite` | Личные запасы, история, настройки, напоминания, ключи |
| `data/recipes.sqlite` | Ранее собранная база рецептов |
| `tests/` | Проверки правил и API |

По умолчанию сервер слушает только `127.0.0.1`; это локальная версия для одного
домохозяйства. Перед многопользовательским размещением нужны аккаунты и
разделение данных пользователей. Для резервной копии личных данных остановите
сервер и сохраните `data/fridge.sqlite`.
